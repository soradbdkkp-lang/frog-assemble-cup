# ふろぐ Assemble Cup 大会ルール

2026-10-29のユーザー確定事項を最優先とする。今回変更指定のない禁止事項・再使用制限・ペナルティ等は既存Assembleサイトの本文を維持する。ふろぐCup Vol.1・Gambit Cupから追加のルールを転記しない。Vol.1から明示的に採用するのは予選総合Pt同点時の判定順のみ。

- 開催日：2026年11月14日、16:00開始予定。参加7チーム。
- 予選Aは3チーム総当たり、全3試合、各チーム2試合。
- 予選Bは4チームが各2試合を行う全4試合。4チーム総当たりではない。
- 各ブロック予選総合Pt上位2チームが準決勝へ進み、決勝を行う。
- 応募受付終了。締切日は非掲載。別システムの応募フォームは変更対象外。
- 担当キラー・サバイバー・リザーブは未確認。メンバー名だけを掲載。
