## 応募形式と参加区分
応募形式は「キラー用」「1人用」「2人用」「4人用（サバイバーのみ）」「4～6人用（キラー・サバイバーのチーム）」です。ルール上は、完成したチームを次の2区分で扱います。
応募形式と完成後の扱い応募形式 / 編成方法 / 参加区分 /
キラー用・1人用・2人用 / 運営が編成。2人応募は原則ペアを分割しません。キラー応募者は専任／サバイバー兼任可能を申告します。 / 個人・ペア参加 /
4人用 / 固定のサバイバー4名に、個人応募のキラー参加者から運営がキラーを編成します。 / チーム参加 /
4～6人用 / 登録したチーム内でキラー・サバイバー担当を決定します。 / チーム参加 /

## 対応プラットフォーム・応募条件
対応機種はSwitch・Steam・PlayStationです。プラットフォームごとに応募区分を分けません。
各チームに、日本語を理解し会話できるメンバーが1人以上必要です。この条件を満たす韓国チームも応募できます。

## 事前構成提出は行いません
使用キラー、キラーパーク、キラーアドオン、サバイバーパーク、サバイバーキャラクター等の事前構成提出は行いません。
総当たり・予選など準決勝より前の試合では、キラー担当者から事前に希望MAPを聞いてMAPプールを作成します。準決勝と決勝は指定MAPプールを使用します。MAP希望確認と同時にパーク・アドオンの提出は求めません。

## 試合前の構成確認

- 運営はキラー側／サバイバー側を個別に確認し、相手チームへ構成を共有しない。
- サバイバーはMAPへスポーンするまで使用キラー／MAPを知らない。キラー側にもサバイバー構成を事前共有しない。
- 確認対象は、使用MAP・キラー／サバイバーキャラクター・パーク・アドオン・アイテム・オファリング・禁止スキン等。
- 運営によるVC確認後も、MAP以外のキャラクター・パーク・アドオンは試合開始直前まで変更可能。変更後の構成ミスはすべて各チームの自己責任とする。
- スポーン前に発見された構成違反はペナルティなしで修正可能。
- ロード中に違反へ気付いても、修正目的で故意に切断しない。運営へ申告する。

## リザルト・異議申し立て

- 各試合終了後、両チームともリザルト画面のスクリーンショット提出必須。
- 異議申し立ては次の試合開始前までに運営へ申告し、証拠を提出する。
- 証拠のみで判断できない場合は、リザルト、録画、クリップ、公式配信、当事者双方の説明、運営確認状況等を総合して運営が最終判断する。
- 次の試合開始後の申し立ては原則受け付けない。

## VC・ゴースティング

- 運営が試合を案内し、出場者がカスタムロビーへ入室する前まではリザーブ・コーチを含めチーム内相談可能。
- カスタムロビー入室後は、サバイバーVCは出場4名、キラーVCは担当キラー1名のみ。リザーブ・コーチ・第三者は試合終了まで一時退出する。
- 試合中断中も同じVC制限を維持する。
- 死亡／脱出したサバイバーも、そのサバイバー試合が完全終了するまでは出場中として扱う。サバイバーVCに残り、DBD標準の観戦機能で得た情報を共有できる。
- 自分が出場中の試合では、相手・味方を問わず外部配信、大会公式配信、Discord画面共有等からリアルタイム情報を得ることを禁止する。
- ゴースティングが明確な証拠とともに確認された場合は重大違反として扱う。

## 配信・公開投稿

- 大会出場者による個人ライブ配信は禁止。
- ローカル録画は可能・推奨。必須ではない。
- 自分が出場した試合終了後は、その試合の録画・動画・クリップを公開可能。
- 大会・参加者・運営への誹謗中傷、個人攻撃、晒し、悪意ある印象操作は禁止。
- ゲーム内チャット・公式配信コメント等での過度な挑発や攻撃的行為もペナルティ対象となる場合がある。

## メンバー変更・欠場

- チーム編成確定後のメンバー変更は原則不可です。
- やむを得ない事情がある場合は運営へ連絡してください。無断でのメンバー変更は禁止です。
- 個人・ペア参加から編成されたチームで欠員が発生した場合、必要に応じて運営が代替参加者を編成する場合があります。
- チーム参加は登録メンバー内での対応を基本とします。
